# jd-instruction-writer

通用技能：先问清公司、届次、城市和岗位，再写一份可交给任意 AI 或 Agent 执行的招聘 JD 采集指令。

**第一作者：** 何天娇。这是个人独立完成的作品，供大家免费使用。它不是任何公司的任务，也不属于任何公司。

License: [MIT](./LICENSE) © 2026 何天娇

## 文件

| 文件 | 作用 |
|------|------|
| `SKILL.md` | 提问顺序、指令框架、字段和筛选判断 |
| `reference.md` | 接口核实与避坑 |
| `examples.md` | 一份完整指令，以及提问示例 |
| `README.md` | 使用说明 |
| `LICENSE` | MIT |

## 怎么用

支持 Skills 的产品：把整个文件夹放到该产品的 skills 目录。

只支持自定义指令：把 `SKILL.md` 放入系统提示或项目说明。

普通对话：上传或粘贴 `SKILL.md`，并说「按这个技能，先问我，再写采集指令」。

```bash
git clone https://github.com/19867688061j-ship-it/jd-instruction-writer.git
```

## 默认行为

信息不全时先提问。信息确认后，输出一个可整段复制的文本代码块。只有用户明确要求执行时，才真正采集并生成 Excel。

## 使用边界

本技能只指导采集公开招聘接口上的岗位信息，供个人求职整理使用。请遵守目标站点服务条款与当地法律；不要用于登录绕过、验证码破解或未授权访问。
